# Todo App
A simple Todo List application built using React and Vite.

## Features

- Add a new task
- Mark tasks as completed
- Delete tasks
- View total number of tasks
- View completed task count
- Responsive and clean user interface

## Technologies Used

- React
- Vite
- JavaScript
- CSS

## Project Structure

```
src/
├── components/
│   ├── TodoApp.jsx
│   └── TodoItem.jsx
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```

## Installation

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Navigate to the project folder.

```bash
cd Bhavika
```

3. Install dependencies.

```bash
npm install
```

4. Start the development server.

```bash
npm run dev
```

5. Open the browser and visit:

```
http://localhost:5173
```

## React Concepts Used

- Functional Components
- JSX
- useState Hook
- Props
- Event Handling
- Conditional Rendering
- Rendering Lists using `map()`
